# 度昂订单与价格工作台

Windows 10/11 x64 原生 WPF 便携程序。使用系统 .NET Framework 与系统 SQLite，不启动浏览器，不运行 Web 服务。与中台服务及其数据库独立。

## 构建和验证

在 Windows PowerShell 执行 `./desktop/kingdee-workbench/build.ps1`。产物在本目录被忽略的 `bin/DoonWorkbench.exe`。整个程序目录可移动；数据默认在可执行文件旁 `data/`。需将程序放在本人可写的文件夹，移动时连同 `data` 一起移动。

命令行入口支持 `--self-test --report <path>`、`--check-views --data <isolated-dir> --report <path>`、`--inspect-prices <xlsx> --report <private-json-path>`、`--import-prices <xlsx> --data <dir> --report <private-json-path>`、`--import-materials <xlsx> --data <dir> --report <private-json-path>`、`--import-names <json> --data <dir> --report <path>`。`--inspect-prices` 只读来源，报告含业务资料，必须存放在仓库外。名称 JSON 是 `[{"Code":"TEST","Name":"合成商品","Source":"合成依据"}]`；新增版本保留旧记录。

## 已实现

- 有边界的 OOXML 读取器：保留原文本、公式、单元格位置与完整原件；不运行宏、不加载外链。
- 从明确客户编号、PI 或客户 PO 中的客户段识别客户，不从文件名猜测。解析 Drawing/Model/Colourway/Order qty/Unit/Frame price 等兼容英文表头及部分中文表头；其他版式明确提示未解析。
- 按客户、图纸、色号、正式/样办类型、单位匹配，并核对客款号和 SKU。同角色 PI/PO 优先，候选不同价不自动选择；原单已有价格不覆盖。缺币种、零价、单价公式缓存、隐藏表、起订量附加费或不完整依据保持待核对。
- 仅计算原币种数量乘单价，十进制保存，不自动进行汇率、税率、折扣或取整。历史一致价是核对候选，不代表永久有效价格或已确认订单。
- SQLite 事务写入，来源哈希去重、行号追溯；新文件追加，不覆盖旧记录。完整原件按 SHA-256 归档，保存副本前再次校验哈希。
- 客户价格查询、材质名称对应表、全部字段组合筛选、字段值搜索多选/全选/反选、文本及数值范围、只读详情、原件另存。无分页，先筛选完整集合。名称对应按明确代码查询，与成品编码生成分开。
- 金蝶物料库仅保存五个业务字段：物料编码、物料名称、规格型号、基本单位、物料分类；其余信息在完整原件中保留。去空格编码用于检索和展示，原始编码保存在详情中。不合并同码来源行，不因导入推定启用状态。物料与价格独立记录，后续新清单追加版本。
- 文件读取允许 Excel 占用时共享只读，并连续读取两次校验一致性；发现文件变化即中止。解析读取的是已保存文件，不读取 Excel 中未保存的修改。
- 成品规则库从含“成品编码规则”的工作表导入，明确排除半成品表；保留原规则、原示例和完整工作簿。按规则正文提供六段模板与修正参考，缺图纸号使用不可生成的占位提示，不编造编号；不同类别分开制单的要求可追溯。
- 成品编码页按类别选择板料/电镀分支，校验全部六段，删除空格而保留段内 `+`、`/`、`-`，查询同码物料并提供复制和现有码校验。订单详情可带入客户、图纸、客款号、色号及明确镜片列；类别、板料/电镀等缺项由使用人填写，不猜测，已有金蝶记录不改写。
- 商品名称使用镜架名称加全角括号内镜片名称；镜片规则独立入库，按关键词包含、不区分英文大小写匹配。同一名称的别名可共同命中，不同镜片名称冲突、未知或缺失描述保持待核对。原有金蝶物料名称不覆盖。

新增命令行入口：`--import-coding-rules <xlsx>`、`--import-lens-rules <json>`、`--generate-code <json>`，均支持 `--data <dir>` 与 `--report <path>`。镜片配置格式为 `[{"Keyword":"合成关键词","Name":"合成镜片名称","Source":"合成依据"}]`；编码输入包含 `Category`、`Customer`、`Drawing`、`Model`、`Middle`、`Color`、`FrameMaterial`、`Lens`。生成只返回候选结果，不写业务；编码有效与名称是否有待核对项分别返回。

## 功能边界

| 功能 | 状态 |
| --- | --- |
| 本地价格持久化、版本来源、重复导入 | 合成数据库回归覆盖 |
| 客户识别、合并单元格、冲突/零价/原价保护 | 合成解析与匹配回归覆盖 |
| 物料五字段、原编码、重复来源、价格保全、名称别名 | 合成回归覆盖；新增业务原件另作本地逐值核验 |
| 桌面页面构建 | `--check-views` 检查，不等于实际点击验收 |
| 下拉与组合筛选 | 原生查询界面，人工点击验收需单独记录 |
| 完整 Excel 公式重算、验证、格式、图片、隐藏信息、原版打印 | 在字节完整的原工作簿中保留；使用 Excel 打开副本。程序不提供完整 Excel 引擎 |
| 任意客户订单版式 | 未实现；目前仅支持兼容表头，不能保证任意文件自动识别 |
| 成品编码规则、生成校验、镜片关键词组合名称 | 已接入；原文版本、缺项、复合代码、参考修正、未知/冲突镜片均有合成回归 |
| 金蝶正式导出、BOM、魔你换算 | 尚未接入，保留入口且标明状态 |
| 多用户权限、在线共享 | 未实现，当前是本机单用户资料库 |
