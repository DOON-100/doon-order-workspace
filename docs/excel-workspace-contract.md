# Excel 页面功能与验收约定

用户于2026-10-30要求中台以后所有Excel格式页面保证Excel表格功能。这是长期交付约束，不表示当前HTML表格已经具备完整工作簿计算或编辑能力。

用户已确认当前采用“中台管理和筛选，原生Excel打开编辑／打印”。完整原件归档后下载为作业副本，公式、透视、格式和原版打印由原生Excel完成；副本改动不会自动覆盖原件或直接写成正式业务事实。以后新增Excel格式页面沿用此约定，若改为在线编辑须另行完成实际引擎和往返保真验收。

## 页面类型与真实能力

| 入口 | 必须做到 | 不得宣称 |
|---|---|---|
| 业务表格／共享基础资料 | 全字段下拉、搜索、多选及类型化条件，多列组合；可编辑区域按权限校验并保存版本 | 仅因使用绿色表头就称完整Excel |
| 工作簿字段查询 | 原字段、来源行、保存值和公式可追溯，隐藏信息按授权查看，筛选不改源文件 | 保存时公式结果是当前重算；普通网格是原貌打印 |
| 原始Excel文件 | 字节完整保存、哈希验证、授权下载，全部工作表及包内依赖保留 | 缺失外链会自动恢复，原生文件下载等于网页已支持全部功能 |
| 原生或完整在线工作簿操作 | 在独立作业副本执行计算、透视、格式和打印；与原生基准逐项验收 | 尚未接入的引擎已支持宏、透视或打印 |

## 筛选

- 所有有权限查看的业务字段，包括备注、数值、日期、版本和公式结果均可筛选。表头合并或原版单据不适合加按钮时，用独立字段列表；不破坏版式。
- 使用共享`ExcelTable`及`useExcelColumnFilters`。分页或虚拟滚动必须先以完整授权记录创建筛选模型，再截取显示行；异步服务端分页必须将条件交给后端执行，不能只筛当前页。
- 枚举支持搜索、多选、全选、反选、清除；文本支持包含／排除及精确条件，数值与日期支持比较和范围，空白可选择。不同字段默认AND，同字段多选OR。
- 零、空白、否和错误值按类型处理；编号保留前导零。日期无效时不默默转换成另一日期，数值条件不把‘10支’当可直接汇总的成品数量。
- 过滤、排序和个人查看设置不修改来源、正式事实或其他用户的视图。候选值和数量也必须遵守数据权限。
- 展示过滤条件、匹配数和清除操作。禁止静默限制候选值导致漏查。

## 编辑与业务规则

录入下拉与筛选下拉是两项功能，不能互相代替。复制粘贴、批量填写、增删行、撤销等只在获授权的草稿或资料维护范围内保存。已发出、已收回、已检或已结算凭证通过更正记录调整，不能用撤销或删行抹去业务事实。

共享基础资料维护留稳定ID、版本、操作者和修改内容。其他部门引用时复用同一条目；本部门配置分开，资料修订不能改写已采用报价或已签收单据。

## 计算、显示与打印

对导入工作簿检查公式、共享公式、数据验证、跨表和外部引用、条件格式、批注、隐藏／合并／冻结、透视缓存及打印设置。公式文本、保存缓存和实际重算分别验证。外链缺失或原文件已有错误单独标明，不能以空白或自动修复冒充一致。

网页读取使用有限制的解析器，禁止执行宏或自动抓取任意外链。完整计算与原版打印需要实际工作簿引擎及依赖版本。浏览器未实现的功能须明确列为未完成，而非静默转成纯值表。

正式加工单按冻结的完整单据打印，不受列表筛选漏行影响。筛选结果导出另存查询文件并标明范围，原件下载保持完整字节。打印及往返保存用独立副本验证，不能覆盖来源原件。

## 发布检查

每次涉及表格功能，执行适用业务测试、TypeScript、隔离运行时测试和合成功能验收。重点覆盖末页记录筛选、多列组合、空白与零、日期边界、数值条件、来源稳定、权限、重复提交、原件哈希和完整打印。

新Excel页面需列明功能矩阵：功能、工作表、基准输入、预期结果、实测结果、执行环境及状态。只有实测通过的功能可以标为已支持。用户数据与原件不得提交公开仓库，测试使用合成数据。
