# 线下工程主管确认登记

已经在线下完成主管确认的工程报价，可以由现有管理员或已绑定的工程主管登记确认事实。页面显示“工程主管已确认（线下）”，并保留当前账号作为登记人。主管姓名、确认时间和线上审核签名不会由系统补造。

登记接口 `ie-quote-offline-confirm` 接受当前报价 ID、版本、已关联原件 ID 和确认依据。服务端重新检查报价权限、可编辑状态和版本，验证原件属于同一报价及客户，并检查文件大小、SHA-256 和 XLSX 结构。报价配置了来源摘要时，确认原件必须与摘要一致。成本或人工调整失效时不能登记。

确认使用独立的 `ie_quote_offline_confirmation` 记录，绑定完整报价内容、版本和图纸引用，另记操作审计；不覆盖报价快照。同版本相同登记请求幂等，冲突依据不能覆盖既有登记。报价内容或版本改变后，原确认只在对应历史版本有效，新版本须重新登记。

确认后的列表、总表、单款详情及填写版 Excel 显示线下确认状态，个人工程待办不再把此版本列为待处理。尚缺的业务资料仍可查看，空值与计算规则保持原样。继续编辑时会明确显示未保存修改。

线下确认不改变原线上复核状态机，不授予权限，不写入 `reviewedBy`，也不自动触发工程释放、业务交接、客价批准或邮件发送。原线上独立复核和业务下推的服务端校验保持有效。
