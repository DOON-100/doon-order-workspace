对话页提示 `Set DEEPSEEK_API_KEY to use this provider`，原因是显式创建的 SDK 模型会读取文件密钥，而官方 `/agents/providers` 只检查标准环境变量。文件密钥存在时，原模型可调用，但官方 Provider 返回 `connected=false`；模型选择器通过标准路由创建模型时也缺少配置。

启动 Studio 时使用同一密钥读取与格式检查逻辑，将文件配置同步到服务端进程内的 `DEEPSEEK_API_KEY`。文件为空时清除旧值，无文件配置时保留既有标准变量；读取/格式失败不伪装为已配置。密钥不写入镜像、Docker 环境配置或前端，不修改官方提示条件。更换文件密钥后重建 Agent 容器。`connected` 只表明已配置，上游认证、余额和网络状态仍以实际 API 结果为准。
