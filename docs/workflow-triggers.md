# 可视化业务触发器

实现位于 Agent 测试分支。未部署正式 8787，正式事件采集默认关闭。

## 使用入口

Workflows → Schedules 左侧“编辑与管理” → “配置触发器”，或点击画布的“开始 / 触发器”。先选择业务变更、手动或每天定时，再选择模块和数据对象。新增流程默认使用“读取触发记录 → 人工审核 → 汇总结果”，原有采购合成流程及历史不迁移。

字段目录复用 34 个现有 JSON 业务读取视图（注册表 `experiments/mastra-studio/workflow-sources.mjs`）。返回当前身份已经过客户、记录、价格和业务小组权限处理的字段，包含嵌套对象、明细、原表列与页面数据概览；不枚举原始数据库、密码、会话或私有文件。新增授权 DTO 字段自动进入目录，新业务读取入口须加入注册表。目录本身不返回字段样本值；独立合成预览明确标为 synthetic，其样本不代表正式权限或实际业务字段。

订单计算字段复用既有余额、入仓、包装、工序规则，并提供原表日期 / 数量的规范化字段；采购复用剩余数量、齐货和跟进状态计算。原始字段只读保留。其他模块沿用其授权 DTO 中的计算与汇总结果。未有可见记录的可选字段不会从其他用户或原始库中猜测补齐。

数组子字段可以监听变化或按“包含某个值”匹配。多个数组子条件独立匹配，不代表同一明细。需要同一行同时满足条件时，选择具有唯一稳定 ID 的对应明细对象；没有稳定 ID 的子对象保留在上层记录 / 页面概览中，不按行号猜测身份。查询范围只开放原读取入口明确支持的参数，其他筛选使用条件组，禁止无效参数悄悄退回全量。

## 条件语义

- 新增 / 更新、任一 / 全部监听字段变化、AND / OR 嵌套条件（最多 4 层、100 项）。
- 文本、数值、日期、日期时间、布尔、数组和对象按类型提供条件。支持旧值比较、空值变化和首次进入条件；空值不等于 0，价格十进制比较不转浮点。
- 日期时间无时区按北京时间解释。每天定时使用 Asia/Shanghai，只用当前值条件，每天每条一次；不把无旧快照的定时任务冒充字段变化。
- 发布记录激活游标，不回跑启用前历史。定时发布后从下一个时间点开始；已生效规则重启可检查当天错过的时间点。
- “测试触发条件”使用用户输入的合成前后值，逐项解释命中 / 不命中；可按已保存草稿试运行，人工审核实际暂停，审核弹窗保存当次前后值。

## 事件与运行边界

`WORKFLOW_EVENTS_ENABLED`（内网环境变量 `DOON_WORKFLOW_EVENTS_ENABLED=1`）显式开启事件采集。关闭时不创建事件表、不建立历史基线，不声称已开始监听。业务 `commit` 和内网账号维护的 `saveRecords` 把增量事件与原写入放在同一事务中；失败、版本冲突均不留下可消费事件。

`workflow_event_base` 保存启用时的私有基线，`workflow_event_outbox` 追加每个工作区版本的前后增量。仅在同库中重建历史状态用于权限投影，不恢复或覆盖业务库。原始事件与基线无公开读取 API、不得提交 Git。API 只输出重新授权后的字段 / 匹配结果；隐藏记录、隐藏价格与撤权后历史不得从事件旁路读取。绕过这些保存入口的外部 SQL / 维护程序不自动获得事件接入：检测到版本间隔时停止消费，须核对入口，不静默猜测或自动重建基线。当前不自动清理日志。

自动消费桥仅在既有 Studio 隔离合成模式中运行，且需要事件采集已显式启用、规则已发布、原配置人仍有有效身份与权限。当前配置人来源于真实登录会话，浏览器身份头不构成授权。每次匹配、启动及审核恢复重新验证范围和来源；触发规则按配置人隔离，旧共享合成规则保持兼容。正式 / 云端业务事件桥未启用；无连接时显示合成目录或未启用，不能当作正式字段接通或正式调度上线。

投递键绑定流程发布版本、事件 ID 和稳定记录 ID；启动前追加凭据，执行后追加回执，游标持久化。回执中断先回读原运行；结果不明保留待核对，不盲重跑。人工审核继续绑定真实审核人、载荷指纹、来源、流程版本和有效期。当前节点只产生内部合成结果，不新增正式写单、外发、任意 SQL / Shell 节点；事件产生不等于授权业务动作。
