# IE 报价总表与明细子表

每个款色和数量档分别填写。报价总表显示材料、间接费用和最终价格；电镀、其他外发、直接人工各用独立子表填写部位或工艺、单价与每副用量，合计自动进入总表。标准秒工时只用于工艺分析，不参与计价。

新建报价及新增款色自动带出名称资料中的配件／部位清单，单耗和系数默认 1，价格留空。按实际包含的配件逐项填价，材料基价空白表示不包含，按 0 汇总；价格来源选填。明确填写的 0 单耗或系数仍为 0。缺少的配件可在表尾新增，也可删除不需要的行。

名称来自颜色资料的字段标题，去除“色／颜色”后缀，保留数字及内外部位区别；电镀字段取其部位，条码、批次、纯工艺及泛指字段不加入材料清单。原字段、来源行号与版本保留，按固定 `part-v1` 规则验证。点击名称右侧箭头展开配件清单，再查询中文、原名、英文或编码；上下方向键选择、Enter 确认、Esc 关闭。也可直接手填，修改已选名称会解除引用。选择名称不代填价格、规格或用量，不覆盖历史颜色字典、报价或基价目录。

基础填写格可直接点击输入，Enter / Shift+Enter 上下移动，Tab / Shift+Tab 前后移动，Ctrl+S 保存草稿。可从 Excel 复制连续基础填写列，从当前格开始粘贴矩形区域，按需要自动增行；数字错误、超限或包含人工金额列时整块不写入并提示原因。价格来源直接填写在“依据”列。

金额格默认自动计算，允许输入人工金额并填写原因。明确输入 0 表示零费用；清空或点击恢复按钮会回到自动计算。相关输入改变后，旧人工金额暂停采用，工程人员核对后重新确认。仅修改说明不会重新确认金额。改合计不回写分项，材料损耗仍按逐项金额与损耗率计算。

默认材料损耗为每项 10%，额外损耗只增加所选材料。默认间接费用为每副 13.70 元，可逐项或合计调整。默认 IE 出厂价为人民币生产成本乘以 1.3，美元价格按手填汇率折算；人工美元成本存在时，默认美元出厂价改按该人工美元成本乘以 1.3，两币种独立调整须一并核对。

模具等费用单独收费，不摊入单价。先登记本单收费项目才可调整费用合计，共用模具仍按稳定登记与收费来源防止重复收费。

郑忠伟、杨德周、曲艳红及管理员可填写草稿或退回的报价，页面明确显示可编辑状态或只读原因。实际操作人逐次留痕，参与过同一笔报价填报的人不能审核，包括修订前的填报历史。优先由未参与填报的杨德周复核，其次曲艳红；两位都参与填报时阻止提交，需安排独立复核人。其他业务查看范围和最终客价批准规则沿用原流程。

保存生成版本与字段修改日志，包含自动金额、人工金额、实际采用金额及原因。工程提交后由指定复核人审核，审核通过才能下推业务；业务另定最终客价。历史版本保持只读。

材料清单使用 `ie-cost-v5-material-checklist` 规则。打开可填写的旧草稿时仅在页面预览新口径，核对后保存才生成新版本；旧版及已审核结果继续使用其保存的公式版本。材料空价不会阻止提交，图纸、汇率、工序、外发和人工改价原因等检查仍须完成。

Excel 导出保留原 STYLE 打印版式与图片，附材料、工序、电镀、外发、间接费和人工调整明细。导出中的公式可重新计算；离线修改不会自动回写中台或替代审核版本，正式流转仍以中台已保存并审核的版本为准。
