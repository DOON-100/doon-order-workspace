Doon CLI 0.42.0 员工安装与使用说明
适用：Windows 64 位电脑

一、安装

1. 先把“员工安装包”完整解压到本机。
2. 再解压里面的 Doon-CLI-0.42.0-Windows-x64.zip。
3. 进入解压后的文件夹，双击 install.cmd。不要在压缩包预览窗口里直接运行。
4. 安装完成后，关闭并重新打开终端，以及正在使用的 Codex / WorkBuddy。
5. 在新终端输入：
   doon --version
   显示 0.42.0 即表示程序入口已可用。

安装包已包含运行环境，不用另外安装 Node.js。程序按当前 Windows 用户安装；安装失败时，把报错交给管理员，不要自行修改电脑安全策略。

二、首次连接与登录

公司中台地址：{{DOON_EMPLOYEE_ORIGIN}}

1. 安装完成后，在新终端复制执行：
   doon setup --server {{DOON_EMPLOYEE_ORIGIN}}
   这里使用公司公网 HTTPS 根地址，不加 /customer-projects、/api 或 :8787；不要改成 http:// 或 localhost。
2. 员工本人在终端输入：
   doon login
   按提示输入自己的账号和密码。
3. 登录后输入：
   doon whoami --json
   核对显示的是自己的身份。如果提示必须修改初始密码，先到公司中台网站修改，再重新登录。

不要把密码发给 Agent 或其他人，不要分享本机登录会话。CLI 只能执行当前账号已有权限内的操作。

三、日常使用

使用 Codex / WorkBuddy 时，把本使用说明和安装包解压目录中的 README.md 交给它阅读，再用自然语言说明任务。具体服务器地址以本使用说明为准。比如：查询我负责的客户项目，并列出待跟进事项。

描述修改任务时，请说明具体客户或订单、要修改的内容和依据。涉及金额、客户关联、审批、业务承诺等判断，先核对清楚；工具不能替代既有业务审批。

自己查看命令目录：
   doon commands --json

查看某个命令的参数：
   在该命令后加 --help

完整命令和业务说明在解压目录的 docs 文件夹中；README.md 也是供 Agent 使用的入口。当前本期范围为 413 条命令，另有 12 条金蝶命令暂缓使用。

四、遇到问题

- 提示未登录或登录过期：本人重新运行 doon login。
- 提示没有权限：联系管理员核对账号和业务范围，不借用别人的账号。
- 提示版本冲突：重新查看记录，核对别人是否已更新。
- 提示超时、结果未知或回读失败：先查询原记录或批次，不要连续重复提交。
- 提示服务器版本不兼容：交给管理员处理，安装 CLI 不会自动更新服务器。

反馈问题时提供 CLI 版本、操作名称和报错即可；不要发送密码、会话或不必要的业务原件。

五、更新与文件保管

以后收到新版本，使用同一个 Windows 用户运行新版 install.cmd；安装后重新打开终端和 Agent。本次安装保留旧程序和本机配置，不修改服务器业务数据。

安装包旁的 SHA256SUMS.txt 可供管理员校验文件。请从管理员提供的可信渠道接收本员工包。
