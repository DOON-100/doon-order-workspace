# 首批固定程序工具

2026-10-20。主线实现 A1 表格检查/提取、A2 客户归属导出、B1 单张草稿费用维护，入口在「业务工具 → 固定程序工具」。仅限真实登录且有效的管理员，所有者标记只保留初始账号保护，不再影响工具能力。代码交付与正式部署分开，8787 服务须另行发布才会出现新入口。

## 责任与操作

| 功能 | 固定程序负责 | 人工负责 | LLM |
| --- | --- | --- | --- |
| XLSX 检查和行提取 | 验证文件及范围、保留原字节、列出工作表和隐藏状态、输出单元格地址/原值/公式/缓存/未知原因、生成独立 JSON | 上传获授权的原件，选择工作表、表头和范围，核对未知项 | 不参与 |
| 客户归属导出 | 验证显式客户集合，人员条件只取交集，投影责任字段，保留来源版本和摘要 | 选择客户及人员，核对缺失的明确归属；程序不从姓名推断人员编号 | 不参与 |
| 草稿费用维护 | 校验现有报价、费用字段白名单、版本和全文摘要；原子保存新版本/历史/审计/回执，回读核验 | 修改既有模具费和附加费金额，查看差异，明确确认、拒绝或暂缓 | 不参与 |

报价费用入口只接收既有行的 `toolingFee` 和既有 `customerCharges` 的 `amount`。行数量、顺序和编号必须与原草稿一致。程序保全其他业务字段、原附件、模板引用及既有历史；仅正常递增版本、更新修改人/时间并追加历史和审计。空白金额为未知 `null`，不默认为零。修改价格、数量、客户、文字说明、条款或增删项目仍使用原业务入口。

费用预览有效 30 分钟，绑定真实创建人、客户、原报价完整摘要、载荷、差异、规则版本和到期时间。确认时重新校验。来源变化或过期须重新预览；拒绝和暂缓不改报价，暂缓后不能直接批准旧任务。一次事务写入报价、不可变历史版本、审计与完成回执，重复确认只回读原回执。

## 文件与任务边界

- XLSX 输入上限 10 MiB；ZIP 最多 256 条，单条解压 8 MiB、合计 32 MiB，实际解压与声明均检查；最多 64 工作表、100,000 个存储单元格。超限拒绝，不静默截断。
- 解析设置固定 10 秒协作式时限，在解压块、XML/单元格遍历及 SheetJS 调用前后检查；超时不返回结果。SheetJS 同步调用无法中途抢占，此限制不等于可强制中断工作进程；生产容量仍须单独验收。
- 行提取要求明确的单个工作表和 A1 范围，最多 1,000 行、100 列、10,000 格；表头行 `0` 表示无表头。网页只展示前 20 行，完整受限结果可下载。公式只展示文本和已有缓存，不计算；没有缓存、空白及错误保留未知状态。图片、宏、拆分、合并、写回及旧 CLI 的其他操作不开放。
- 原件和 JSON 结果存入应用对象存储，生成后回读 SHA-256，下载时再次校验。不接受客户端文件路径、数据库路径、构建目录、Shell、SQL 或身份声明。
- 新任务使用独立 `fixed_tool_job` 记录。费用提案仅保存严格费用载荷和全文摘要，不复制内部成本快照。公开任务投影不返回存储键；通用订单审计流不展示工具任务，下载走独立鉴权入口。
- 每次创建使用 `requestKey`；同一用户同键异载荷拒绝，同键同内容查询原任务。客户停用、管理员角色撤销、账号停用或非任务创建人不能继续查看/下载。客户筛选不是授权。
- 任务结果不明时查询原任务 ID 或原请求编号，核对保存的历史版本/产物摘要，不自动生成新请求重试。同步费用事务在数据库中只有“待确认”或“已提交”；不会持久化一个可能与实际报价脱节的“执行中”状态。回读失败返回错误并保留原回执供核查，不自动回滚已保存业务。
- 对象写入先于任务发布，事务失败可能留下无引用的随机对象；它们没有可下载任务句柄，不覆盖任何原件。清理须独立核对引用，当前实现不自动删除文件。只读操作会增加自己的任务/结果/审计，不改已有业务记录。

## API 与源码

全部接口位于相对 URL `/api/workspace/` 下，由现有登录会话和同源检查建立身份。

| 接口 | 用途 |
| --- | --- |
| `GET fixed-data-tools` | 授权客户、人员、草稿选择及本人最近 100 个任务 |
| `POST fixed-tool-workbook` | multipart `file, operation, requestKey`，可选 `sheet, range, headerRow, includeEmpty` |
| `POST fixed-tool-ownership` | JSON `requestKey, customerIds`，可选 `memberIds`；最多 100 个客户/人员 |
| `GET fixed-tool-quote?id=…` | 单张草稿的费用编辑投影 |
| `POST fixed-tool-fees-preview` | `requestKey, quoteId, version, lines:[{id,toolingFee}], customerCharges:[{id,amount}]` |
| `POST fixed-tool-fees-decision` | `id, previewHash, decision`，决定为 `approve/reject/defer` |
| `GET fixed-tool-job?id=…` 或 `?requestKey=…` | 读取原任务，已完成任务重新回读核验 |
| `GET fixed-tool-file?id=…&artifact=source/result` | 按当前权限和摘要下载原件或结果 |

实现文件为 `lib/fixed-tool-workbook.ts`、`lib/fixed-tool-fees.ts`、`lib/fixed-data-tools-common.ts`、`lib/fixed-data-tools-api.ts`。界面为 `app/fixed-data-tools-panel.tsx`。新入口在应用内实现已登记的有限业务操作，不动态导入或执行旧操作员 CLI；旧 19 个脚本及未选子操作保留原维护边界。

## 阿里云迁移准备

这批代码没有本机盘符、用户名、绝对模块导入、Python 环境或工作目录依赖。模块使用相对引用/项目 alias；浏览器使用同源 URL；数据库和附件使用既有 `DB` / `BUCKET` 绑定。Standalone 由现有运行时把绑定落到部署指定的数据目录，不能在浏览器或任务参数中改变根目录。

迁到 Linux ECS 时使用仓库的 Node 依赖和 standalone 构建，不复制 Windows 的 `node_modules`。在服务器重新安装锁定依赖，显式设置 `DOON_BUILD_DIR` 进行构建；启动时显式设置 `DOON_DATA_DIR`、`DOON_HOST` 和 `DOON_PORT`。目录由服务器部署配置决定，不写入业务源码或数据库任务载荷。`DOON_DATA_DIR` 必须挂载持久存储，保持数据库与对象文件一起迁移；不可只迁 SQLite 而遗漏 `files/`。既有正式数据迁移仍须在线一致性备份、附件校验和明确的发布窗口，不能重跑历史导入代替迁库。

本次验证包含更换工作目录后的工具运行，并检查没有产生相对本机文件；这不能替代真实 ECS 的文件权限、反向代理、TLS 和容量验收。本次没有连接阿里云或部署任何服务。
