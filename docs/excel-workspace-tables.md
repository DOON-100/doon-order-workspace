# 工作空间 Excel 表格

工作空间中的记录表沿用原栏目顺序、导航、分页、固定列、编辑入口及业务权限。表格使用统一网格线和表头下拉按钮；客户跟进清单、报价历史清单使用相同表格呈现。

表头支持搜索候选值、多选、仅选搜索结果、清除此列与清除全部。多列条件同时生效，单列多选为任一选中值。空白与零值分别处理。筛选仅影响浏览器显示，不提交业务操作，不保存到数据库。

## 接入方式

- `app/excel-table.tsx` 的 `ExcelTable` 保留原生表格结构和已有行节点，读取当前显示值与编辑器值。展开详情、附件和沟通行随所属记录筛选。合并行作为整体保留。
- 未分页的原生表格直接使用 `ExcelTable`；公共 `Table`、`Grid`、`CPTable` 已接入。
- 分页、虚拟滚动或截断列表先使用 `useExcelColumnFilters` 筛选完整的当前授权数据，再分页／截取。将同一 `filterModel` 传入表格，确保下拉选项覆盖整份列表。
- `getValues` 应按实际显示列顺序返回显示值，隐藏列或栏目顺序变化时重置条件。值读取必须尊重原权限范围。选择框等非数据字段使用 `data-excel-no-filter`。
- PMC 已有数据层表头筛选继续沿用；虚拟表格保留原行高与滚动算法。
- 表头筛选不会改变原业务汇总或服务端导出的口径。服务端仍只接收原上方筛选条件的导出按钮已注明“上方条件”；原始文件、完整档案下载保持原用途。

## 验证

运行 `node tests/excel-table-filters.mjs` 验证空白、零值、多列、多选、跨分页与刷新后的筛选语义。

运行 `node tests/serve-excel-table-fixture.mjs` 打开独立合成验收页，默认端口 18879。该页不连接业务 API，覆盖分页末尾记录、编辑草稿、选中状态、附件关联行、合并单元格、双层表头和原生弹窗。

正式服务更新按 `AGENTS.md` 的发布边界执行；合成验收页不是正式中台入口。
