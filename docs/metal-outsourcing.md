# 金属外发

入口为“半成品外发 → 钛架部 → 金属外发”。原“工序跟进”、共享类型及工序资料、原Excel归档入口继续保留。

## 数量与来源

- 同客户、同销售订单、同款式归集全部有效SKU，颜色不作为拆单或确认条件。部分来源不可见时不返回不完整的款式组。
- 工程确认BOM配件、版本、单耗和工艺；PMC采用本批计划。销售订单量、计划量、配件需求量和实际可发物料分别记录。
- 同订单多个款式可合并相同配件和工艺需求，保留每份计划的贡献数量。不同订单的明细不能混成一个总数，同供应商可以共用单据表头。
- 需求占用不因收回而释放；取消未执行记录才释放占用。新金属记录采用独立`metal_*`类型，不更新原订单、`ledger`工序完成数或旧`outsource/receipt`记录。
- 备货引用来源订单的实物凭据，实发前校验可用量。收回、质检、计费、领用分开；不良实物属于收回，不能自动当作报废。
- 合格共用配件保留在订单可用量，生产按款实际领用。不得把配件的粒、支、套直接写成成品付数。

## 办理次序

1. 在“来源与BOM”核对款式全部SKU，维护配件及工程BOM，确认后采用PMC本批计划。
2. 在“需求”选择一份或多份同订单计划的BOM配件行，确认共同工艺和需求数量。
3. 维护供应商报价并由有权限的人员确认采用。数量单位与计价单位不同必须明确换算；空价与明确零价分开，零价须有免费依据。
4. 创建加工单，关联采用报价的快照。确认备货凭据，按实际批次准备送货单，再确认实际发出和供应商签收。
5. 分批登记实物收回，再登记计费合格、免费良品和不良。返工关联原不良，保持往返记录。
6. 生产按款领用合格配件，保留费用归属。物理领用不根据计划比例自动伪造。
7. 选择账期内可计费明细编制供应商对账单，确认后记录月结；付款凭据独立登记。扣补及更正保留依据，不覆盖已发生凭证。

加工单部分发出后，尚未被送货草稿占用的余量可以凭依据关闭，再按新的供应商或已确认报价建立加工单。关闭量以独立记录保留，原加工单数量、已发数量及采用价格不变。关闭后若保留量低于原报价数量下限，系统拒绝继续默认采用原批量价，需先确认价格处理；不会重算历史金额。

网页当前支持按数量、单位换算及已确认单价计费。按批收费、最低收费和供应商之间直接转厂尚未实现，不能用虚拟收回或普通计件数据替代。已执行计划的源订单身份或数量变更也不会自动覆盖原计划，须核对未执行部分；普通备注及生产进度更新不影响原已采用计划继续办理。

不良处置针对已经实收并质检的物料，尚在供应商处的盘亏、报废核销仍需独立流程。纯负数贷项、退款和供应商异议多阶段审批尚未实现；付款功能登记实际付款凭据，不自动调用银行或金蝶记账。

免费返工表示免收额外返工费。原来尚未计费的不良在返工后成为可计费合格品时，原加工费只计一次；免费良品另行登记并免收加工费。对账按同供应商、同币种编制，计费质检与扣补不得重复进入有效对账单。不同币种的未分配成本分别展示，不相加成为一个金额。

## 原件与Excel

沿用[Excel功能约定](excel-workspace-contract.md)：中台办理与全字段筛选，原生Excel负责完整工作簿编辑、计算与原版打印。保存缓存不等于公式已重算。原件不可覆盖，工作副本不自动回写正式事实。

字段查询使用所有值、公式及错误单元格覆盖的内容范围；外围仅有空白格式的区域不展开。存储范围和原件字节仍完整保存，页面标明实际查询范围。真实的远端值、零、空字符串公式或无缓存公式仍计入范围，超限则整体拒绝，不截断真实数据。预填公式行可查询，但不是自动导入的业务行。

新的系统加工单、无价送货单和对账单按完整单据打印，不受列表筛选影响。它们与归档Excel原版打印分别标识。筛选导出是独立查询副本，不生成新的业务动作。

## 权限与并发

服务端检查内部人员身份、订单来源权限、工作组范围、岗位动作和价格权限。多来源单据全部来源均可见才返回。价格权限应用于嵌套报价快照、费用、成本及打印来源。通用订单审计接口不返回金属业务快照。

写入使用请求令牌、载荷指纹、记录版本和工作区原子提交。相同令牌相同请求只执行一次，令牌复用不同载荷或过期版本返回冲突。校验失败不得留下部分事实。更正通过独立记录留痕，有下游依赖时须先处理依赖，不自动级联改账。

## 历史与上线

确认流程不等于确认历史差异。原表、旧加工单号、原行及原缓存保留。历史已回、尚在外、缺价、日期差异及未知对账状态需按确认范围承接，不能重新生成今天的发出、回货、产量或应付。当前功能不会自动导入桌面或共享盘Excel，也不自动补齐未确认的销售/BOM关系。

所有测试仅使用合成数据。构建设置独立`DOON_BUILD_DIR`，运行设置独立`DOON_DATA_DIR`与测试端口，并禁用外部同步、调度和邮件。不能用构建、提交或测试命令隐式替换8787正式服务。正式部署另按项目数据保全约定执行。
