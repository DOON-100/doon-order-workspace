# 三主体应收、实收与对账

用户2026-11-05确定的业务事实：魔你金蝶账套接客户订单，魔你向度昂大陆下单生产；完工后度昂大陆卖给魔你，魔你卖给度昂香港，香港向海外客户销售。客户主要向香港银行或PayPal付款，也可直接向魔你大陆付款；后者先登记为代香港收款、逐笔确认归属。香港付魔你、魔你付度昂大陆，是内部往来，不能重复算客户回款。

## 当前实现

- 应收工作空间增加“应收实收对账中心”。三张原表全部保留：香港HSBC、PayPal、按客户汇总。整体工作簿字节归档、SHA256去重及授权下载；网页展示原行、字段、公式及保存值。原生Excel保留图片、格式和打印。网页不是Excel公式引擎，不执行外链或宏。
- 原表客户汇总排除小计行，负数与超过两位小数原精度保留；原客户代码不自动推断正式客户。历史DEBIT口径未确认时，不冒充整票应收或今日余额。历史与新增金额分开展示，不能直接相加。
- 新开票上传原件，登记客户、销售主体、唯一应收义务、票号、日期、原币金额、到期日。已有应收使用引用关系，不增加另一笔金额；同主体同票号、同义务防重复。现阶段不自动回写旧应收账、PI或金蝶。
- 实收复用独立实收总表，分别登记收款渠道、实际持款主体、客户与依据；不根据群备注猜客户。魔你代收不能自动冲减香港发票。
- 分配只接受已由朱了青最终确认、明确客户、同币种及同销售主体的独立实收。魔你代香港收款须朱了青另行确认代收归属，绑定实收版本及客户后才能分配香港发票；实际持款公司仍保留魔你，公司间代收结算单独待核对。累计额度计入待确认分配防超配；分配仍由朱了青本人确认，随后新增发票显示未收、部分收款或已收齐。业务客服审核、财务取资料核对、最终确认分别保留。不能代朱了青操作。
- 内部销售单据、已发生转款证据、魔你出口退税材料独立归档，保留金蝶订单、报关及申报编号。资料归档不执行付款、退款、金蝶写账或退税申报，不推定税率、资格或退税额。

## 尚需核对与接通

历史全量账不能凭三表直接自动核销：香港表混合发票与付款明细，同号多行可能代表分次收款；PayPal资料与群图存在退款冲突；客户汇总含客户子代码冲突及原精度问题。逐笔核对净额、手续费、原应收义务及历史截至日，再做期初切换，不能覆盖旧账。

跨主体代收结算、历史数据转期初、退款/贷项更正、冻结对账单跨账合并及金蝶API自动联动仍未接通。本次先提供独立来源、核对及新增业务入口，明确显示范围，不能宣称全链路会计账务自动化已完成。

## 权限与验收

### 逐笔匹配与异常确认

收款中心增加“逐笔匹配与异常确认”。匹配采用独立`collection_match`记录，逐行绑定实收版本、原件SHA256、工作簿SHA256、原工作表行及当时单元格快照。提交所选凭证范围时必须覆盖其全部分笔，不能漏行或重复；整批校验后原子保存，相同清单重放不重复写入。原始应收、实收、附件及账户均不修改。

明确对应建立证据关联；客户/金额冲突、疑似重复、无明确应收、退款及非收款资料分开登记，分配给唯一在职朱了青账号。她本人可以接受当前证据关联、否决或继续补证，核对意见追加版本，管理员不能冒签。来源版本变化时旧匹配立即显示过期。关联及核对意见均不确认银行到账、不执行退款、不核销余额。
