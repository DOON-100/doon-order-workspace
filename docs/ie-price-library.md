# IE 供应商价格、工艺与报价原件

入口：IE 工程报价 → 基础价格目录（供应商价格与工艺库）。使用已绑定的 IE 填报账号或管理员。

## 使用

1. 上传电镀供应商 XLSX，选择类别、生效日期。供应商优先使用表内字段；表内没有时使用填写的供应商。需要时填写准确子表名称。
2. 查看解析预览、原表位置与错误，仅勾选已核实的有效报价，确认导入。空价不能作为零价；明确的 0 价可以保留。重复提交不重复新增。
3. “新增价格 / 工艺”维护材料、电镀、其他外发或标准人工单价；支持供应商、规格、计价单位、架型、颜色、币种和税价口径。停用与改价保存新版本，已采用的报价仍保留旧版本。
4. 手写或扫描报价在“供应商手写报价 / 图片 / PDF 原件档案”上传，可多选 JPG、PNG、WEBP 或静态 PDF，每份不超过 12 MB。不同供应商分批上传。不确定的供应商及日期可留空，价格须人工核实后另建价格记录并关联原件。
5. 工程报价材料行展开“依据”，按相同名称、规格、单位比较供应商报价，再手工采用。电镀、外发、人工同样可搜索、按字段组合筛选选用。含税或外币条目不能直接用于人民币未税成本，须先核实换算并建立对应依据。
6. 人工基价可新增或修订，难度系数由 IE 在当前款工序行填写。费用按基价 × 难度系数 × 每副用量计算；标准秒工时用于分析，可留空。
7. 设计图、PDF、产品图片上传入口位于 BOM 材料区下方，按款式和图纸版本关联，历史版本原件保留。

## 支持边界与核验

| 功能 | 基准输入 | 核验方式 | 状态 |
| --- | --- | --- | --- |
| 电镀价格预览、选行入库及原件下载 | 合成供应商简称、架型、物品名称、单位、颜色、未税价、税点 | API 回归及原件字节比较 | 自动回归覆盖 |
| 人工单价与外发矩阵 | 合成人工单价；胶架 / 不锈钢 / 钛架区间 | API 回归 | 自动回归覆盖 |
| 同物料供应商筛选、全部比价字段 | 同名异规格 / 异单位、外币、含税、零价 | 组件合成交互及 SSR | 自动回归覆盖 |
| 手写原件留底 | 合成 JPG / PNG / WEBP / 静态 PDF、伪装内容、越界文件 | 独立接口回归、哈希及权限校验 | 自动回归覆盖 |
| 版本保留和权限 | 旧版价格、过期版本、撤权身份 | 业务回归 | 自动回归覆盖 |
| 原生 Excel 公式、格式与打印 | 原始 XLSX | 上传原件字节保留；下载后原生 Excel 操作 | 网页不提供完整 Excel 引擎 |
| 手写价格识别 | 照片 / 扫描件 | 原件留底后人工录价 | 不自动识别或采用手写价格 |

上传报价表是结构化价格导入，不是任意格式 Excel 的完整编辑器。公式单价仅保留在原件中，预览不把保存缓存视为已核实价格；不执行宏或主动读取外链。外发区间拆为注明上下限的条目，工程师核对适用架型和实际价格后采用。

源码提交不等于正式服务已更新；真实业务数据、供应商原件和客户图纸不能提交公开仓库。
