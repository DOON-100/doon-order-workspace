# 阿里云员工 CLI 自动升级

## 当前实现与边界

CLI 0.43 增加 `doon update check --json`、`doon update install --json`。两者仅由当前 Windows 用户显式调用，不后台轮询；Agent 可先检查再执行安装。首次仍须按可信渠道安装包含升级命令的客户端。安装后重开终端和 Agent，核对 `doon --version`、`doon whoami --json`、`doon commands --json`。原 DPAPI 会话文件位于用户配置目录，安装器不覆盖；会话未过期、未撤销且服务器地址未变时不重新登录。

0.43.1 修复公网下载与并发安装：安装包传输最长 15 分钟，连接或传输连续 30 秒无进度时停止；普通业务请求的时限不变，也不自动重试。安装器按安装目录使用独占锁，最多等待 2 分钟，锁内重新核对已安装版本并原子切换命令入口。自动升级拒绝覆盖另一进程刚安装的更高版本；人工运行旧包安装器仍可显式回退。`.install.lock` 文件会保留，进程结束后系统释放文件锁，无需删除。升级及安装脚本使用 Windows PowerShell 自带模块，兼容 Agent 继承不同模块路径的环境。

这些修复需先装入客户端才生效；0.43.0 若因原有 30 秒超时或模块错误无法自行升级，应从可信渠道取得 0.43.1 包并运行安装器。此手动覆盖安装同样保留原配置和仍有效的登录凭证。

对没有升级命令的 0.42 客户端，管理员也可单独发布 `cli/windows/upgrade-legacy.ps1`，提供公司 HTTPS 地址和独立脚本摘要。脚本自动定位 PATH 中的正式 `doon.cmd` 安装入口，未找到时检查默认安装目录；非默认且未注册 PATH 的安装可用 `-InstallRoot` 明确指定。登录凭证按客户端原有配置规则读取，与程序位置分开，兼容已有 `DOON_CLI_HOME`。分发命令使用员工电脑的系统临时目录，不写入管理员个人电脑的固定路径。脚本本身可以公开提供，但安装包仍须走原员工鉴权接口，以保留下载审计。更新这个独立脚本后需重新发布摘要，无需重新打包 CLI 或重启中台服务。

中台服务通过现有员工 HTTPS 会话提供 `/api/cli-update/latest` 和 `/api/cli-update/package`。更新目录使用服务器私有配置 `DOON_CLI_RELEASE_DIR` 指向业务数据目录外的独立绝对路径；未配置时返回 404。供应商入口、只读验收入口不提供更新。下载要求有效员工身份且完成初始密码修改，拒绝匿名访问和任意下载路径。服务端核对文件大小与 SHA-256 后才返回包。

检查与下载请求作为独立 `cli_update_event` 审计记录保存账号、成员 ID、时间、来源 IP、版本、提交和包摘要，不记录密码、会话或业务内容。记录的是服务端接受的下载请求，不代表员工已完成安装。管理员可通过 `/api/cli-update/history?limit=50` 查看最近记录；普通员工无权读取他人的下载历史。

## 发布顺序

1. 在隔离目录和合成数据上完成 CLI、内网运行时、安装及回退测试；核对 GitHub CI 来源、成品包和 SHA-256。不得发布 `sourceDirty: true` 的包。
2. 按正式中台发布规则备份代码和一致性数据，再独立部署包含更新接口的服务器代码；发布目录与数据库、附件、运行配置分离。代码提交或推送不触发此步骤。
3. 将经过验收的 Windows ZIP 上传至 `DOON_CLI_RELEASE_DIR`，核对它与 `latest.json` 的文件名、大小、SHA-256、版本和提交。先完成包上传，最后原子替换 `latest.json`。目录只保留当前最新版；切换时若客户端恰好正在下载，摘要不一致会拒绝安装，重新检查即可。
4. 使用少量真实员工电脑核对身份、下载审计、升级后会话复用、命令目录及旧程序回退，再开放给其他员工。旧版本保留在每台电脑的 `programs` 目录中；服务器只保留最新版不影响本机旧版回退。

`latest.json` 格式：`format: doon-cli-update-v1`、`version`、`commit`、`file`、`bytes`、`sha256`、`sourceDirty: false`。Windows 打包流程在干净源码上自动生成。更新包及清单只通过原公司 HTTPS 地址提供；服务器必须使用受信任的 TLS 证书和原员工入口。发布权限由服务器管理员控制，员工会话仅获得读取权限。此版本采用 HTTPS 与服务端文件摘要校验，尚未加入离线数字签名；若将发布目录交由第三方托管，应先增加签名验证。
