# 按原 Excel 公式先生成 IE 报价

工程报价可显式选择原表公式模式，先形成最终工厂价格计算结果，再由 IE 核对和修改。生成结果保留工程草稿状态；不会自动提交、审核、释放或发送。修改通过原有保存入口创建新版本，原报价、附件及审核权限保留。

## 计算范围

该模式复现已明确的工程报价公式路径，不执行用户输入的公式文本，也不提供任意 Excel 工作簿的通用计算引擎。

| 原表位置 | 计算含义 | 中台结果 |
| --- | --- | --- |
| 材料金额行 | 逐行计算并四舍五入到两位小数 | 材料明细金额 |
| 材料损耗合计 | 对材料金额计算损耗，汇总后保留两位小数 | 材料损耗 |
| H62 | 材料含损耗、电镀、外发、直接人工及间接费用合计 | 生产成本人民币 |
| H63 | H62 ÷ 成本换算汇率 | 生产成本美元 |
| I66 | H62 ×（1 + 成本加价率） | 人民币加价中间值 |
| I67、C73 | I66 ÷ 美元报价换算汇率 | 最终工厂报价美元 |
| D73 | C73 × 最终人民币换算汇率 | 最终工厂报价人民币 |

保留三条原表换算路径。采用统一汇率时，三条路径同时使用指定汇率，并在报价版本中保留参数与来源说明；不会自动抓取市场汇率。最终换算使用未提前舍入的计算链，页面金额格式不改变内部计算值。采用“成本加价率”表述，避免把成本加价误称售价毛利率。

## 空白与审核

原表公式模式下，参与金额运算的空白按原表规则以零计算，原始空白字段仍保留为空，便于 IE 后补。价格为零、尚未填写和明确不适用仍可区分；页面显示核对提示。颜色、图纸版次、数量档、模具收费依据等审核条件继续独立校验，不能因已经生成金额而自动视为确认。

来源文件名、摘要和公式版本是本次计算的来源引用。仅填写引用不等于系统已经上传或验证该工作簿原件；原件留存与引用信息应分别核对。原生工作簿的外链、打印及其他未复现功能仍遵循 [Excel 页面功能与验收约定](excel-workspace-contract.md)。

## 兼容性

未选择新模式的报价沿用原计算规则。历史快照不回算、不迁移，旧客户端不能静默清除已经采用的公式模式。人民币及美元的人工调整继续保留金额、原因和对应计算依据；依据变化时提示重新核对。导出的填报稿保留待审核标识，并与该保存版本使用相同公式路径。
