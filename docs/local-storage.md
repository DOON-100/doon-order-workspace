# 本机存储与迁移约定

用户于 2026-11-01 要求将本项目全部本地文件迁往 E 盘，并将此约定写入项目记忆。该约定适用于这台 Windows 开发机器；不改变服务器部署路径，也不修改其他协作者的机器。

## 固定位置

| 内容 | 本机物理位置 |
| --- | --- |
| 主仓库、代码、文档、脚本和 Git 历史 | `E:\DOON\doon-order-workspace-main` |
| 同仓库工作树 | `E:\DOON\worktrees` |
| 原 Agent 独立测试工作树 | `E:\DOON\doon-mastra-local-test` |
| 本项目独立的 Codex 聊天素材及 PDF/DXF 工具环境 | `E:\DOON\codex-project-files` |
| 项目临时文件 | `E:\DOON\.tmp` |
| 项目工具缓存 | `E:\DOON\.cache` |
| 本机跨工作树记忆 | `E:\DOON\PROJECT_MEMORY.md` 和 `E:\DOON\AGENTS.md` |

数据库、附件、原始文件、历史资料、构建结果、日志和备份随所属项目目录迁移，仍保留原有私有目录及 Git 忽略边界。8797 的程序和数据位于主仓库的 `.workbuddy/local-test-8797`，当前状态记录在 `.workbuddy/local-test-environment.json`。

## 后续操作要求

- 命令显式以 E 盘目录为工作目录。新增代码、脚本、文档、数据、导出物、构建、测试和备份都写入 E 盘；不要在桌面或 Codex 默认目录另建本项目副本。
- 项目命令需要临时文件时，设置进程级 `TEMP`、`TMP` 为 `E:\DOON\.tmp`；npm 等工具缓存使用 `E:\DOON\.cache` 下的对应子目录。这是本项目操作约定，不修改 Windows 或 Codex 跨项目的全局设置。
- 优先复用已有 E 盘工作树。使用工作树工具前确认其实际创建位置；工具若只能创建在 C 盘，不直接采用该默认位置，也不为本项目擅改影响其他项目的全局工作树设置。
- 日常用户测试只使用 [8797](http://127.0.0.1:8797/engineering-drawings)，复用已有服务器数据副本和账号。程序升级不重新初始化数据库、不创建替代账号、不重置密码。自动回归仍使用独立合成数据；详细边界见 [固定本地测试环境](local-test-environment.md)。

## 旧路径与 Codex 范围

旧 C 盘主目录、相关工作树及项目专属工具路径保留目录联接，实际文件位于 E 盘，用于兼容旧聊天、快捷方式和历史配置。目录联接不是第二份数据，不能按旧路径递归清理，也不能删掉联接后在原位置重建副本。后续操作直接使用表中的 E 盘路径。E 盘必须保持可用，盘符不能随意改变。

用户明确选择只迁移能单独归属本项目的 Codex 文件。跨项目共用的数据库、聊天索引、会话记录、设置、日志、缓存、Codex 应用和其他项目保留原位置。本规则不要求改写 Codex 共用数据库或清理其他项目；因此 Codex 界面中的部分历史项目地址可能仍显示 C 盘兼容入口。

## 迁移校验与保全

迁移须保留隐藏文件、Git 历史、各分支及未提交改动、原始数据库、账号和附件。所有文件核对路径、数量、大小及目录联接；业务文件和非依赖文件校验内容哈希，可重建依赖缓存另行注明核对方式，不能把大小与时间检查宣称为逐文件内容哈希检查。切换前再次核对源目录没有新增或变更，验证通过后才清理已迁移的旧物理副本。

启动 8797 后核对健康接口、匿名访问保护、测试标识，以及记录和账号保持一致。详细文件清单、数据校验和迁移过程保存在本机私有目录，只向公开仓库提交操作约定，不提交业务数据、账号凭据或私有配置。迁移、提交和推送均不触发云端或 8787 正式部署。
