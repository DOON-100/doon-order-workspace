# 客户项目跟进人筛选

项目清单的“事项跟进人”按该项目所有未完成事项的实际跟进人筛选，保留逐人多选、跨列组合和零结果提示。筛选不会改变事项负责人或任何访问权限。

只有明确指定的人员可以作为“尚无事项”的额外筛选候选，不能默认加入全部员工。部署页面可用 `customer-project-extra-follower-ids` meta 的 `content` 配置 JSON 成员 ID 数组。发布工具写入 HTML 属性时须正确转义；配置缺失、格式错误或空数组时，不添加额外人员。配置还须与当前已授权返回的启用内部成员取交集，不能因此暴露未返回的人员。

实际人员 ID 只保存在私有发布配置和服务器回退材料中，不写入公开源码或测试。后续发布必须保留已批准的该项配置，不能按全员名单重新生成。新增待办继续使用既有候选接口和服务端授权，此配置只控制清单的额外筛选候选。

专项检查：`node tests/customer-project-list-filters.mjs`；隔离浏览器验收：设置 `DOON_BUILD_DIR` 后运行 `node standalone/test-customer-project-assignee-browser.mjs`。测试只使用合成人员和临时环境，验证已有跟进人加一个明确指定人员，其他未分配人员不进入筛选。


## 项目责任与个人待办（2026-11-06）

- 清单分别展示业务负责人、客服负责人、事项跟进人。业务和客服来自项目主档，事项跟进人来自全部未完成的项目行动、跨部门待办及客户跟进；无未完成事项显示“尚未安排下一步”，有事项但没有执行人显示“待指派”。完成事项不会清除项目负责人。
- 清单保留开发阶段，按用户要求移除“负责部门”和“项目状态”两列；项目维护中的状态和事项中的部门仍保留。每个展示的业务列保留下拉、搜索及组合筛选。多名客服按单人筛选，筛选只使用完整授权数据，不修改责任或任务。
- 清单可直接“指派待办”。创建前重读项目权限与人员，只有一名符合条件的项目客服时预填，多名时明确选择执行人；部门默认客服，仍允许按既有权限指派内部跨部门人员。项目责任不扩大客户权限。
- 项目维护可勾选“保存后安排下一步”；先保存主档，再填写并保存具体事项。已有事项不自动改派；在各事项中逐条移交、填写原因并保留历史。勾选本身不创建任务。
- 个人页保留原协作任务，并展示原项目行动、客户跟进及“我负责的项目”。旧项目行动按当前跟进／客服审核／业务审核阶段投递，点击打开原ID继续原流程；不复制成另一种任务，不绕过审核。跨组个人任务不受页面组筛选隐藏，客户项目详情仍检查原授权。
- 保存后回读事项与项目清单，并使个人待办缓存失效。其他已打开的客户端可点击“重新读取”或“刷新项目待办”取得最新资料；这不是消息推送或站外通知。

专项验收：`node tests/customer-project-list-filters.mjs`、`node tests/customer-project-personal.mjs`、`node tests/project-collaboration-ui.mjs`；隔离浏览器验收：设置独立 `DOON_BUILD_DIR` 后运行 `node standalone/test-customer-project-responsibility-browser.mjs`。全部使用合成数据；8797只做实际测试副本上的只读界面核对，不运行写入式自动回归。

界面宽度沿用工程画图表的内侧留白：桌面表格左右各18px，小屏12px；项目工作区居中且最大1560px。宽表在自身容器内滚动，项目清单的“客户、项目”两列固定在左侧，其余列横向滚动。冻结偏移随实际列宽和拖动调整更新，表头与内容使用统一单线边框；项目名称下同时展示业务／客服责任人。

## 清单直接办理与表格操作

- 日常操作留在项目清单。点击项目名称维护主档；行内记录进展、指派待办；“查看待办”“历史记录”分别打开对应窗口。关闭窗口保留清单筛选，不再进入整页详情。原图纸、报价、样办、财务、原件与审核入口保留在“更多项目资料”，仍读取原记录和原权限。
- “项目进展记录”保留人工填写的日期与情况，不把任务回复复制为进展。“关联客户跟进”继续引用原跟进记录。项目行动仅在待办窗口和指定行动入口出现，沟通窗口沿用自身行动表，避免同一事项出现两次。
- 指派请求实际打开后即消费；取消、保存、切换记录类别不重新打开空表。跨组“保存后安排下一步”使用当前登录会话内的一次性意图，不写入URL；刷新和分享链接不创建或重放指派。旧指派URL只打开项目记录。
- 个人待办与负责项目在限定客户／项目范围时显示提示，可通过“查看全部我的待办”清除范围，保留未保存内容的离开保护。
- 项目清单、进展记录和关联客户跟进保留左右留白，并支持顶部横向滚动和拖动表头分隔线调列宽。列宽只作为本浏览器按表保存的查看设置，不修改业务数据、原始附件或其他人的视图；表头筛选仍基于完整授权记录。
- 表格不再限制固定高度，随页面或记录窗口自然向下展开。项目清单先显示30条，接近底部自动追加30条，直至显示全部；也可点击“加载更多项目”。下拉候选、组合筛选和匹配数量始终计算完整授权清单，先筛选再分批显示；切换客户或筛选后重新显示首批。清单顶部的横向操作条随页面滚动保持可用。

这些是网页业务表格功能，不代表完整原生Excel引擎。原始工作簿、公式与打印仍沿用原件／原生Excel约定。
