## 范围与数据保全

补强服务端的轮次UUID范围绑定、供应商报价版本/UUID及外协新增源订单版本/指纹；兼容网站原调用。新CLI先读取相应契约，旧服务器写入前拒绝。无请求去重的原接口不宣称自动幂等。

采购净合格/退补核数不等于库存和质检放行；计划和产能是独立记录，不自动派工/扣库存。成品本批只接员工分类、发布任务及期初核定；供应商接单/复期/进度、收发品质按W6继续。业务操作保持原审批与角色规则，CLI不新增操作确认。

金蝶采购源表preview/commit/held继续暂缓，预览实际保存批次/原件；purchase-change-*维持网站提案确认，不接入CLI批准读取/传递。直接员工业务请求使用原采购接口，模型提案依旧需对应人工审批；不把聊天日志当批准凭据。

所有测试只用合成账号、独立数据目录和测试端口，正式服务器、真实ERP/MES和真实外发请求均为0。原记录、关联、历史及原件保持；仅专用合成业务夹具按测试动作增量改变，另核对原来源字段。测试模块自动删除本次数据库、会话和临时文件，安装验收结束再清理其独立目录，不改用户PATH。未部署、停止或重启8787；提交和推送不代表部署。
