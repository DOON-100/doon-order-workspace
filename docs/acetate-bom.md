# 板材整副BOM

入口：IE工程报价 → 板材整副BOM。沿用IE查看、填报和客户授权，未新增账号或放宽报价权限。

固定规则版本为 `acetate-bom-20261110-v1`：圈长总加10、上下各加3；冲脾长总加10、上下各加2；拼脾精雕长总加10、上下各加5。40/60板厚代码归一为4.0/6.0毫米。已含余量毛坯不重复加量。庄头、嵌块和冷拼分段选独立工艺卡，记录自己的余量及依据。

单色在横竖两个规则网格中取出数较多者；条纹先分段，渐变与条纹使用指定方向。先开块时独立记录原板切缝、投料块尺寸、块内扣边和拼后有效区。未提供的切缝、修边与尺寸不默认为零。

整副以组件逐层计算：圈主料通常1件，左右同料脾通常2件，庄头每层按实际2件或4件。不同色号、供应商、板厚或原板规格分别计算；相同物料标识和规格汇总标准条/副、公斤及材料费。组件出数不能相加冒充齐套出数。订单领料先按每个独立排版需求取整后汇总，未假设不同组件可在同一板混排或重复抵扣余料。

保存使用服务端重新计算、乐观锁及幂等请求；`acetate_bom`为当前记录，`acetate_bom_version`为每次不可变版本。查看详情和旧版本不写业务数据；不修改现有报价、订单或金蝶。板材BOM仅含圈、脾、庄头各层，其他配件另列。

标准用量保留精度，重量可选确认值、历史参考或密度理论值。缺重量/价格不按零汇总，也不再叠加IE报价默认损耗。CSV为全量板材BOM复核，不是金蝶官方导入文件，不表示完整Excel引擎。

实际规格、重量与来源是受控业务资料，存于独立`acetate_bom_catalog`记录，不打包进公开源码。管理员接口`acetate-bom-catalog-import`增量保存版本；通用维护工具`import-acetate-bom-catalog.mjs`默认只预览，校验来源摘要，`--apply`时经API导入并核对全部原记录字节不变。已有不同规格库拒绝维护覆盖。原Excel不修改。

验证：`node tests/run.mjs`、TypeScript检查、隔离构建及`node standalone/test.mjs`；`standalone/test-acetate-bom-browser.mjs`使用合成数据库及随机端口，实点圈/脾/庄头录入、汇总、保存回读、详情、历史、CSV下载并保全旧记录。生产发布独立执行备份及版本核验。
