# 板料清单

入口为采购 → 板料清单。所有有效内部员工可查阅基础资料，外部供应商不可访问。原始统一清单含报价，仅沿用现有采购价格查看权限开放；网页基础查询不返回报价。

每个目录版本独立保存原始工作簿、来源摘要、标准字段和真实颜色图片。按供应商、板料编号、尺寸、厚度、材料、产地等全量筛选后分页；详情显示完整字段和可点击来源。缺失值保留空白。系列说明和无编号规格可查阅，不能当作具体板料引用。色卡成镜效果图会注明类型，不视为板料正面图。

工程整副BOM通过“选择板料”填入供应商、编号、厚度及明确的长宽。混合尺寸不能自动拆分；选择板料后仍须核对尺寸与厚度。板料编号不自动等同金蝶编码，未确认映射保持空白。修改关键用料字段会解除引用，避免图文不符。

中英内部订单可选择多个部位板料，插入中文颜色、编号、尺寸和厚度，并显示颜色图；中文缺失时由使用人填写核实。保存时服务端读取真实目录，冻结所选资料及图片；后续目录更新不会改写历史订单或BOM。修改用料需重新核对PMC图片确认。订单Excel保留原工作表，并另附“采用板料”及嵌入图片、部位、资料版本。原模板未增加图片占位的栏目仍按原模板保留。

当前不自动转换客户销售原表的全部颜色栏位，不支持库存占用、实时库存、采购承诺或自动替代料。应逐步补充：ERP物料映射、样板编号与实物确认、供应商批次色差、停产状态维护、订单允许替代范围、厚度公差、MOQ及交期确认。资料中的交期为供应商资料，不代表当前可交货承诺。

## 私有资料导入

使用通用工具 `scripts/data-tools/import-acetate-materials.mjs`。显式设置 DOON_DATA_DIR，提供 --build-dir、--input、--source；默认只读预览，--apply 才上传。只允许一个有效主管理员身份；通过正式鉴权处理器分批暂存，所有批次完整才发布版本。原始文件须与SHA256一致；重复源不重复导入。既有记录逐字节校验不变。真实资料、输入、图片、结果和备份不进入公开仓库。

发布程序与业务导入分开执行。更新前在线快照并保留代码回退点，更新后核对原记录、附件及账号；不使用旧库覆盖新业务。
