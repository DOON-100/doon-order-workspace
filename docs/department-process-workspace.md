# 度昂部门与工序工作台

左侧导航按部门分为一级目录，各部门下直接列出二级工作入口。部门顺序与客户开发、接单、工程、计划、采购、生产、交付、回款及售后衔接；检验和资金条件贯穿多个阶段。

点击部门名称展开或收起。售后与复盘归入“客服与单证”，客诉整改和已完成订单档案排列在该部门入口末尾，保持二级结构。打开某个页面时，该部门自动展开，当前二级入口高亮。键盘可用 Tab 选择入口，Enter 或空格激活，部门按钮可用左右方向键展开或收起。窄屏下二级入口分两列展示。

页面显示受当前账号权限限制。客户报价与历史报价沿用报价授权；系统维护沿用部署能力和角色条件；业务工具沿用所有者管理员条件。目录调整不增加任何客户、订单或操作权限。

## 按业务流程工作

在“工作总览 → 端到端业务总览”查看十三阶段的输入、输出、交接部门和完成条件，再打开对应工作入口。自制、工序外协、成品委外和现货出货分别展示；具体订单按其产品、资料及工艺选择适用路径。

已有客户、订单、报价、生产、供应商、物流和财务业务继续在原页面维护。原生产计划与供应商管理总览仍保留，原链接仍可使用；原页面下的常用子页已直接列入二级导航。

采购、半成品外发、外发电镀分别是独立一级工作空间。半成品外发和外发电镀按原外发记录的工序筛选，共用已有供应商资料与权限；列表、待回数量、登记工序、收货明细和交期导出沿用相同范围。跨工序送货单在各空间仅展示相应明细，原凭证保持完整。原 `supplier-outsourcing` 链接继续显示全部工序，入口与成品外发一并保留在“生产车间”，不迁移或改写历史记录。

新增流程工作页补充十四类事项：需求询价、签样、工程变更、来料检验、齐料、仓储流转、首件、过程检验、外协检验、成品检验、包装、出货条件、供应商结算及客诉。每类事项使用独立作业记录关联获授权客户或订单，并记录：

- 执行负责人、最终负责人、计划日和实际完成日；
- 输入依据、采用版本、输出证据及关口结论；
- 阻塞事项、下一步动作、负责人和截止日期；
- 对应业务类型需要的数量、批次、检验或单据引用；
- 保存版本和历史变更记录。

通过侧栏切换工序时，保留当前客户、项目和订单范围，清除上一页专属记录编号与页签。切换客户或工作组后，以新范围内能读取的记录为准。选择某人为负责人不会给该成员新增数据访问权限。

“已完成”需要实际完成日、结果证据、执行及最终负责人，关口通过或注明不适用依据，并清理尚未解决的阻塞。检验数量、齐套数量等按相应规则核对。资料不足时保持“待核实”或“受阻”，继续指定下一步责任与时限。

## 数据保全与业务边界

本次结构调整保留原记录、主键、历史版本、附件、账号及客户范围。新增事项使用独立的流程作业记录和修订记录；修改时核对版本，避免覆盖其他人的更新。

新流程页用于交接、依据和异常跟进。登记仓储、包装、出货或供应商对账事项不会自动改写原库存、生产数量、实际出货、收付款或财务记账。实际执行仍以对应业务系统和原业务单据为准。包装入仓、生产完工、客户签收和财务到账分别核对。

源码通过检查、提交或推送不等于正式部署。正式更新须按项目既有发布流程保存代码回退点和一致性数据备份，并在更新后核验原记录与附件；不能用旧数据库覆盖运行期间新增数据。
