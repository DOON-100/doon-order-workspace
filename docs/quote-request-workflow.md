# 报价需求表与 IE 待办

入口：业务部 → 需求与询价评估 → 报价需求表。

1. 新增报价需求，选择已有授权客户，填写需求名称和报价截止日期。
2. 在款式表中填写款号、客户款号、颜色、数量、材质、图纸版本及报价要求。客户原文可以直接粘贴到需求说明中。
3. 保存草稿并上传附件；支持 PDF、JPG、PNG、WEBP、TXT、CSV、Excel、Word，每个文件不超过 12 MB，每单最多 20 个。
4. 点击“发送给 IE 工程师”。系统沿用 IE 工程报价中绑定的工程主填账号，显示实际收件人；姓名相同的其他账号不会收到待办。
5. 工程师登录后，在“我的待办”查看报价需求，打开原文和附件，点击开始报价。系统创建并关联一份工程报价草稿，带入款式与数量要求。
6. 工程师按原 IE 工程报价流程填写成本、提交复核。工程版本发布后，需求显示已报价，后续业务定价仍沿用现有流程。

提交后的原始需求与附件作为报价依据保留。报价金额不会从客户要求中推测生成。工作组筛选不影响工程师接收本人的跨组待办。

原“询价与需求评估”作业仍可从“原询价评估记录”进入；本功能不转换或覆盖原作业、客户、订单或工程报价。草稿与附件操作有版本校验、重复提交保护和历史记录；移除附件引用保留原件。

实现使用独立的 `quote_request`、`quote_request_revision`、`quote_request_attachment` 记录。权限在服务端校验，附件下载核对当前授权及原件哈希。既有账号权限与 IE 角色配置不由本功能更改。

验证使用独立测试数据库及端口：`tests/quote-request-cases.mjs` 覆盖权限、版本、附件、待办和报价复核；`standalone/test-quote-request-browser.mjs` 覆盖业务填写、上传、提交及工程师登录接单。源码提交不代表正式部署。
