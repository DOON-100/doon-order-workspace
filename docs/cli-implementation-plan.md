## 明确暂缓

批次 0 不接业务查询/写入、任意 URL/action、旧数据库维护脚本、金蝶直传或新审批页面。普通员工权限继续由中台校验。沿用的 Cookie 拥有员工原有权限，客户端命令列表不构成服务端只读隔离；需要该隔离的功能在对应批次另行接入服务端限制。

首版支持 Windows x64 持久登录；其他系统仅支持不依赖凭据保存的基础命令。公司地址、配置、密码、会话、业务文件均不进入公开包。程序和用户配置分别保存。

每次推进更新本页状态，并在 [执行记录](cli-execution-log.md) 追加日期、完成项、检查结果、阻碍和下一步。区分“代码已实现”“合成测试通过”“员工实机验收”“发布/部署”；不将其中一种自动当作另一种。容量验收使用隔离环境和合成数据；实际员工安装、两种 Agent 实机联动和正式分发单独留证。
