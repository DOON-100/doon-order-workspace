# 采购部跟单总表

入口：供应商收货 → 采购部跟单总表 / 已交货档案。

Candy、Tina 的 PMC / 采购账号可共同维护；其余成员按原订单查看权限查询和导出，财务和生产管理可以查看全部。源表来自金蝶，不改变生产订单或 MES。

## 每日跟进

1. 选择采购员、供应商、交期范围或跟进状态；也可搜索采购单号、商品编码、客户订单及备注。
2. 表格保留源行顺序。浅绿色单元格可直接填写供应商复期、预计到货、下次催交、采购备注。离开单元格或按 Enter 保存，Enter 向下、Tab 向右。日期填 YYYY-MM-DD。
3. 点击“专注表格”扩大工作区域，横向滚动查看其他列。“展开原表全部字段”显示金蝶原始状态、备注等信息。
4. 选择供应商后点“提取该供应商 Excel”；导出包含当前全部筛选明细，不只屏幕上可见的行。导出的 Excel 可继续筛选。
5. 保存失败时输入保留；同字段冲突须核对服务器最新值，再选择自己的输入或采用最新值。

## 收货、退货、补货

如果金蝶导出表没有已收 / 剩余数量。所有初始明细显示“待核对”，不能把源表数量当剩余数。

首次点“核对已收数量”，核对截至业务日期的累计净合格已收数、退货待补数、核对凭证号和依据。核实没有时明确填写 0。

- 已收数量：当前净合格已收，已经扣除退货，包含已补回数量。
- 剩余数量＝采购数量－净合格已收；包含退货待补，不能再把两列相加。
- 普通收货：本次合格数量增加已收；不能占用退货待补份额。
- 退货待补：减少已收、增加待补。
- 退货补回：增加已收、减少待补。
- 核对更正：有凭证时更正累计基数，旧记录和修改依据留存。

数量按源单位记录，支持四位小数，不跨单位汇总。每次需填业务日期、实际单据 / 核对凭证号、说明；同明细同类凭证不能重复登记。此功能不推定照片识别结果，也不自动写入 MES 或生产工序。

## 已齐货与存档

已审核且未关闭、已核对收齐、退货待补为 0 的明细显示“已齐货 · 待存档”。采购确认齐货日期与依据后，点“已齐货，存档”，或选择至多 100 条明细批量确认。

存档明细从在跟表移入“供应商已交货档案”，可按供应商、订单查询和导出，保留数量、操作人、日期、凭证和历史。同单其他未齐行继续跟进。档案后发生实际退货，可在档案记录退货，自动回到在跟表。

金蝶手动关闭不等于齐货；未审核、手动关闭的源行保留查询，须先在金蝶核对并重新导入状态后才能登记收货或齐货。

## 后续更新金蝶表

“更新金蝶表”上传原格式 XLSX，填写导出截至日期，先预览再分批确认。相同文件不会重复导入；唯一匹配的采购组合更新来源字段并保留网页跟进、收退数量和历史。多行不能唯一匹配、已记账数量/单位发生不兼容改变、旧日期回退等会暂缓，可导出暂缓原因供核对。缺失行不自动删除，也不自动齐货，因为金蝶导出可能带筛选。
