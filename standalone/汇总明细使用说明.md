# 动态订单总表：汇总明细与跨部门跟进

状态：开发与验收完成，待用户确认上线。正式网站尚未更新。

四张汇总卡各新增“查看明细”按钮。打开后以 Excel 式表格浏览，表头和订单号固定；可搜索、按客户/跟单员/当前工序筛选，点击表头排序，并选择每页 50、100 或 200 行。

| 汇总 | 点击后内容 | 数量说明 |
|---|---|---|
| 有效订单 | 按订单号汇总；点击订单号展开款色明细 | 按授权范围实时统计 |
| 进行中明细 | 在制、未取消且欠数大于零的明细；无效欠数沿用原卡片口径 | 按授权范围实时统计 |
| 已包装入仓 | BF 大于零的订单明细；MES 报工单列 | 按授权范围实时统计 |
| 待核对明细 | 订单异常、未匹配报工及更正待办，可按事项类型筛选 | 按授权范围实时统计 |

## 浏览和跟进

1. 点击任一汇总下的“查看明细”。明细按汇总本身的完整授权范围打开；总表下方已有筛选不会改变卡片口径。
2. 在明细窗口内筛选；窗口同时显示全部汇总数、筛选后数量和明细条数。
3. 点击订单号或“打开订单跟进”，进入该条稳定明细编号对应的原订单，在“订单跟进”中维护备注、跟进事项及期限；仍按原账号权限控制。
4. 未匹配报工可通过“进入 MES 核对”继续处理。
5. 勾选“显示全部工序与跟进列”，横向查看工序数量、日期和记录来源。

## 导出 Excel

“导出筛选明细”导出全部筛选结果，不限于当前页。有效订单含“订单汇总”“明细与跟进”“导出说明”；其他三项含“明细与跟进”“导出说明”。

文件保留订单号、稳定明细编号、原表行号、色号与真实圈色、跟单员、BF/BG、工序字段、异常原因、现有待办及跟进期限。末尾提供责任部门、跟进责任人、计划完成日期和跟进结果四列，供各部门在 Excel 中填写。文件中的填写不自动回写系统；系统内持久跟进请打开原订单。导出说明记录版本、时间及筛选条件。

汇总、明细和服务端导出共用统计规则。导出时重新检查账号可见范围；若共享数据版本已改变，提示刷新明细后再导出。待核对按事项计数，同一订单可同时存在订单异常和更正待办，不擅自去重。包装入仓只取 BF，不与 MES 包装报工相加。
