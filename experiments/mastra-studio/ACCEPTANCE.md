## 能力边界

这是官方 Studio 的可运行本地接入，测试 Agent 使用确定性离线模型，执行同一合成采购场景。它验证 SDK 调用、工具、工作流、记忆、轨迹和入口权限，不验证真实模型推理质量。未接真实订单、企业微信发送、定时巡检、生产多租户记忆隔离、动态岗位授权、人工审批或真实业务闭环；后续按总体设计继续实现。
